# phishing_analyzer - dipendenze Python
#
# Le dipendenze sono divise in:
#   - core: necessarie per eseguire l'orchestratore e i moduli lexical;
#   - tls:   necessarie per i moduli TLS (modulo `cryptography` per parsing
#            certificati avanzato; il modulo stdlib `ssl` è comunque sufficiente);
#   - dns_whois: per WHOIS e DNS (python-whois, dnspython);
#   - content: per fetch HTML e parsing (requests, beautifulsoup4, lxml);
#   - dynamic: per headless browser (Playwright);
#   - nlp: per analisi semantica (spacy + modello italiano, opzionale);
#   - vision: per clonazione visiva (Pillow + imagehash, opzionale);
#   - reputation: per API threat intel (requests già incluso);
#   - ui (opzionali): rich o questionary per UX più ricca.
#
# Installazione minima (solo lexical + tls):
#   pip install -r requirements.txt
#
# Installazione completa:
#   pip install -r requirements.txt
#   pip install -r requirements-extra.txt
